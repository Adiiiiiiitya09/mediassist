## 🚀 Quick Start Instructions

### 1. Download Datasets
- Source: https://www.kaggle.com/datasets/itachi9604/disease-symptom-description-dataset
- Files needed: dataset.csv, Symptom-severity.csv, symptom_Description.csv, symptom_precaution.csv
- Place in: `backend/ml/`

### 2. Configure Environment
- Edit `backend/.env`:
  - Add ANTHROPIC_API_KEY
  - Add SECRET_KEY (any long random string)
- Keep other defaults as-is

### 3. Train ML Model
```bash
cd backend
pip install -r requirements.txt
python ml/train_model.py
```
Expected output: `Accuracy: 1.0000`

### 4. Start Backend
```bash
# From backend directory
uvicorn main:app --reload --port 8000
```
API docs: http://localhost:8000/docs

### 5. Start Frontend
```bash
cd frontend
npm install
npm run dev
```
Application: http://localhost:5173

## 🔐 Ethical Constraints Implemented

All constraints from the document are enforced in code:

1. **Patient Data Privacy** (routes/consultation.py)
   - Patient API endpoint returns ONLY {reply, is_complete}
   - Disease predictions stored in Report table, never sent to patient
   - ⚠️ Comment clearly marks: "NEVER return disease data to patient"

2. **Role-Based Access Control** (routes/doctor.py)
   - All doctor routes verify JWT token role == 'doctor'
   - Return 403 Forbidden for patient tokens
   - Doctor-only endpoints explicitly check authorization

3. **Confidence Transparency** (forms/ConfidenceMeter.jsx)
   - Always displays disclaimer: "This is a data quality indicator, not diagnostic certainty"
   - Score capped at 99% (never 100%)
   - Color-coded feedback (green/yellow/red)

4. **AI Behavioral Constraints** (services/ai_interview.py)
   - System prompt explicitly forbids mentioning ANY disease
   - "NEVER suggest, hint at, or mention any disease or diagnosis"
   - "NEVER say 'it could be X' or 'this sounds like Y'"

5. **Doctor Authority** (backend design)
   - Predictions are suggestions only
   - Doctor must explicitly approve before patient sees any results
   - Doctor adds notes and prescription (optional)

## 📊 Data Flow

```
1. Patient starts consultation
   ↓
2. Patient chats with Claude AI (10-14 exchanges)
   ↓
3. Interview complete → Messages saved to DB
   ↓
4. Claude Scribe extracts structured JSON
   ↓
5. Symptoms mapped to 131-feature binary vector
   ↓
6. ExtraTreesClassifier predicts top-5 diseases
   ↓
7. Report saved to DB (DOCTOR ONLY visibility)
   ↓
8. Patient sees: "A doctor will review your case shortly" ✅
   ↓
9. Doctor logs in → Sees pending consultation list
   ↓
10. Doctor clicks consultation → Full report loaded
    - Confidence meter with disclaimer
    - Patient summary + vital flags
    - Top 5 AI suggestions (doctor exclusive)
    - Full interview transcript
    ↓
11. Doctor adds notes + prescription
    ↓
12. Doctor clicks Approve/Reject
    ↓
13. Consultation status updated in DB
```

## 📝 Notes for Developers

1. **ML Model Training**: The first time you run `python ml/train_model.py`, it will take a few minutes to train on 4,920 samples. This is one-time setup.

2. **Database**: SQLite database is created automatically in `backend/` on first run. It will be named `telehealth.db`.

3. **JWT Tokens**: Valid for 7 days. After that, user must login again.

4. **Confidence Scoring**: Formula is `min(top_probability × symptom_coverage × quality_multiplier × 100, 99.0)` to ensure it never reaches 100%.

5. **API CORS**: Frontend at `http://localhost:5173` is whitelisted in `main.py`. Change if running on different port.

6. **Production Deployment**: 
   - Never hardcode API keys in code
   - Use environment variables for ANTHROPIC_API_KEY
   - Use proper SECRET_KEY in production
   - Disable `--reload` flag in uvicorn
   - Use a proper ASGI server like gunicorn+uvicorn
